Vice Grid turns your own photos into a GTA 6-style multi-panel cover: six layouts (Nine-Panel Classic, asymmetric Hero + Three, Full-Bleed Hero, Tilted Snapshots polaroids, Diptych Split, Strip Comic), five colour grades including the teal-magenta Teal Dusk, original Anton + Pacifico lettering (SIL OFL, vendored), per-panel captions, undo/redo, deterministic grain and vignette — and one-click PNG export in four post sizes (1080×1080, 1080×1350, 1920×1080, 1080×1920). Fully offline, vanilla JS + Canvas 2D, no network requests, no Rockstar artwork or fonts.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
